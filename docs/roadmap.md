# Roadmap

This roadmap is a public view of the Praxys product direction and open source launch plan.

## Open source launch

Praxys is being developed as an open source product. The repository will feature a clear public roadmap, documented setup instructions, and contribution guidance.

## Product phases

### Phase 1 - Foundation

- scaffold the frontend and backend
- create the app shell and navigation
- implement authentication basics
- build task and goal management

### Phase 2 - Core Productivity

- add focus sessions
- add habit tracking and streaks
- add dashboard analytics
- improve UX and loading states

### Phase 3 - Accountability

- add social relationships and accountability partners
- add activity feeds
- support shared goals and challenges

### Phase 4 - Growth

- add gamification and richer analytics
- explore AI-assisted recommendations
- grow the contributor community

## Monthly progress plan

### Month 1

- launch the repository with core documentation
- complete MVP foundation features
- invite early contributors to review and contribute
- track progress with weekly issue updates

### Month 2

- expand focus, habits, and analytics
- polish onboarding and documentation
- add issue templates and contribution guidance
- begin community outreach

### Month 3

- complete social accountability features
- improve stability, testing, and deployment readiness
- publish a public release note or announcement
- establish a regular release cadence

## How to use this roadmap

Contributors should refer to this roadmap when prioritizing issues and planning iterations. Use it as a coordination tool for public work on the project.
